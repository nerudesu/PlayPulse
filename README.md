# Spotify Now Playing Image Generator

A Flask application that generates a PNG image showing your currently playing Spotify track.

The generated image includes:

* Album artwork
* Song title
* Artist name(s)
* Album name
* Release year

Perfect for:

* GitHub Profile READMEs
* Personal websites
* Streaming overlays
* Discord integrations

## Features

* Spotify OAuth authentication
* Real-time currently playing track retrieval
* Album artwork rendering
* Rounded album cover corners
* Dynamic font resizing
* PNG image endpoint
